# Локальная разработка

Docker-окружение поднимает Bitrix24 Box с модулем `easybusychats`, подключённым из репозитория. На хосте нужен только Docker.

| Сервис | Назначение |
|---|---|
| `web` | PHP 8.2 и Apache, портал на `http://localhost:8080` |
| `db` | MySQL 8.0 с настройками, которые требует Bitrix |
| `seed` | Один раз копирует дистрибутив в том `portal` и завершается |
| `module-sync` | Постоянно копирует каталог `easybusychats` из репозитория в портал |

Также понадобятся распакованный дистрибутив Bitrix24 и, для работы чатов, `Client ID` и `Client Secret` компании EasyBusy. Для чатов нужен доступ в интернет: frontend и API EasyBusy работают удалённо.

## Запуск

Дистрибутив по умолчанию ищется в `~/Work/bitrix24_encode`. Другой путь и остальные параметры задаются в `.env` (см. `.env.example`).

```bash
docker compose up -d --build
```

Первый запуск занимает несколько минут: копируется около 1,7 ГБ файлов.

## Установка портала

Откройте `http://localhost:8080/` и пройдите мастер установки.

| Поле | Значение |
|---|---|
| Лицензионный ключ | `DEMO` или ваш ключ |
| Сервер БД | `db` |
| Пользователь и база данных | существующие |
| Имя пользователя | `bitrix` |
| Пароль | `bitrix` |
| Имя базы данных | `bitrix` |

Для администратора укажите email пользователя компании EasyBusy: вход в чаты определяется по точному совпадению email.

После установки проверьте ключ шифрования, без которого нельзя сохранить `Client Secret`:

```bash
docker compose exec web php -r '$s = include "/var/www/html/bitrix/.settings.php"; echo empty($s["crypto"]["value"]["crypto_key"]) ? "missing" : "ok", PHP_EOL;'
```

## Установка модуля

1. Откройте `http://localhost:8080/bitrix/admin/module_admin.php?lang=ru`.
2. Найдите **EasyBusy Chats** и нажмите **Установить**.
3. Заполните настройки модуля, как описано в [инструкции по установке](installation.md). Используйте Sandbox-компанию: адреса по умолчанию ведут на рабочие сервисы EasyBusy.

## Разработка

Сервис `module-sync` примерно раз в секунду копирует каталог `easybusychats` в `/var/www/html/local/modules/easybusychats`. Изменяйте файлы только в репозитории: правки внутри контейнера будут перезаписаны. Прямой bind mount не используется: файловая система macOS не различает регистр, и автозагрузчик Bitrix находит классы не так, как на Linux.

- Изменения PHP и файлов `assets/` применяются после обновления страницы.
- Файлы `install/public/` копируются при установке модуля, поэтому после их изменения скопируйте их снова или переустановите модуль.
- Изменения схемы применяются при следующем открытии страницы после повышения версии в `install/version.php`.

## Тесты

Тесты лежат в каталоге `tests` репозитория, вне каталога модуля, и в поставку не входят. Они монтируются в контейнер `web` вне корня сайта и запускаются только из командной строки.

```bash
# Не требует установленного портала
docker compose exec web php /var/www/tests/phone-normalizer.php

# Требуют установленного портала и модуля
docker compose exec web php /var/www/tests/access-policy-smoke.php
docker compose exec web php /var/www/tests/phone-link-integration.php
```

## Управление окружением

```bash
docker compose logs -f web   # журнал Apache и ошибки PHP
docker compose stop          # остановить, данные сохраняются
docker compose down          # удалить контейнеры, данные сохраняются
docker compose down -v       # удалить также портал и базу данных
```

Журнал модуля при включённой диагностике: `http://localhost:8080/bitrix/admin/event_log.php`, записи модуля `easybusychats`.
